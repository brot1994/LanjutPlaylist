# Lanjut Playlist

Aplikasi Android kecil supaya ganti playlist di YouTube Music **lanjut dari lagu terakhir**, bukan dari awal.

- Tambah playlist: di YT Music → Bagikan → *Lanjut Playlist* (atau tempel link).
- Tap playlist → YT Music terbuka dan lompat ke lagu + detik terakhir.
- Butuh izin **akses notifikasi** (untuk membaca lagu yang sedang diputar).

APK dibuild otomatis oleh GitHub Actions (tab *Actions* → artifact `LanjutPlaylist-apk`).
